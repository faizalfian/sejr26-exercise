📋 Perintah Pengerjaan Form 2
  1. Buat Form Baru: Beri nama berkas dan class FrmDataSetoran.cs.
  2. Atur Properti Form: Text = "Kelola Data Setoran Sampah Siswa — GreenSchool Bank Sampah", Size = ~980, 680 piksel, StartPosition = CenterScreen.
  3. Susun Navigasi & Struktur Kontainer:
    • menuStrip1: Menu File, Transaksi, Laporan, Bantuan.
    • grpEntriData: GroupBox formulir input data setoran.
    • pnlAksi: Panel tombol aksi CRUD.
    • grpTabel: GroupBox riwayat dan pencarian data.
    • statusStrip1: 4 item status label di bilah paling dasar form.
  4. Konfigurasi Input Data (grpEntriData):
    • txtKodeSetor: ReadOnly, warna latar kontrol.
    • txtNIS (MaxLength 10) dan txtNamaSiswa (MaxLength 50).
    • cmbKelas: DropDownList berisi daftar rombel kelas.
    • dtpTanggalSetor: DateTimePicker format Short.
    • cmbJenisSampah: DropDownList kategori sampah & tarif.
    • numBerat: NumericUpDown desimal 1 digit, rentang 0.1 - 100.0 kg.
    • txtTotalNilai: ReadOnly, rata kanan, font tebal.
    • rdoTabungan dan rdoDonasi: Opsi radio button mutually exclusive.
  5. Ketentuan & Ukuran Panel Tombol Aksi (pnlAksi):
    • Tipe Kontrol & Nama: Panel, Name = pnlAksi.
    • Ukuran Panel (Size): 940, 50 piksel (Lebar: 940 px, Tinggi: 50 px).
    • Posisi (Location): X: 18, Y: 275 (terletak di antara formulir entri dan tabel riwayat).
    • Properti Panel: BorderStyle = FixedSingle, BackColor = SystemColors.ControlLight (abu-abu muda), dan Anchor = Top, Left, Right.
    • Ukuran & Tata Letak Tombol: Masing-masing tombol berukuran Size = 130, 32 piksel dengan jarak renggang (*gap*) 8–10 piksel. Tombol btnBatal diposisikan di sisi paling kanan panel.
    • Daftar Tombol: btnTambah (Text = "➕ Tambah Baru"), btnSimpan (Text = "💾 Simpan Data", warna tema hijau), btnUbah (Text = "✏️ Ubah"), btnHapus (Text = "🗑️ Hapus", warna merah), dan btnBatal (Text = "🔄 Batal / Bersihkan").
  6. Konfigurasi Pencarian & DataGridView (grpTabel):
    • Fitur pencarian: txtCari, cmbFilterKategori, dan btnCari.
    • dgvSetoranSampah: ReadOnly, FullRowSelect, AllowUserToAddRows = False, minimal 7-10 kolom, serta masukkan 3 baris data sampel realistis.
  7. TabIndex, Naming Convention & Anchor Responsif: Beri awalan standar pada setiap objek kontrol (txt, btn, cmb, num, dtp, dgv). Urutkan TabIndex secara sekuensial. Atur Anchor agar tabel melebar saat form dimaksimalkan (*Maximize*).
