Ujian Praktik Pemrograman GUI C# .NET Desktop

Windows Forms App Kelas 11 SMK RPL

🎯 Skenario Kasus: "GreenSchool — Bank Sampah Digital"

Sekolah Anda sedang menggalakkan kepedulian lingkungan bertajuk Green Campus melalui unit Bank Sampah Siswa. Setiap hari, siswa menyetorkan sampah anorganik (botol plastik, kardus/kertas, kaleng logam, minyak jelantah). Hasil penimbangan sampah dikonversikan menjadi saldo rupiah yang dapat disimpan ke buku tabungan siswa atau disedekahkan ke kas donasi sosial sekolah.

Sebagai Junior Desktop Developer, Anda ditugaskan merancang antarmuka (GUI) aplikasi pencatatan loket berbasis Windows Forms (.NET C#) yang terdiri dari:

  1. Form 1 — Login Petugas (`FrmLogin.cs`): Autentikasi petugas loket sebelum masuk ke sistem.
  2. Form 2 — Form CRUD Data Setoran (`FrmDataSetoran.cs`): Halaman kerja utama untuk mencatat transaksi setoran, memilih jenis sampah, menimbang berat, menentukan opsi penyaluran, serta memantau tabel riwayat.
💡 Ketentuan Utama Ujian Praktik Desain UI:
Pada ujian ini, Anda hanya diminta mendesain tampilan (GUI) secara presisi di Visual Studio Designer. Belum diperlukan koneksi database SQL maupun kode simpan/ubah data yang rumit. Penilaian difokuskan pada ketepatan tata letak (*layouting*), pemilihan komponen kontrol standar yang tepat, struktur pengelompokan (*GroupBox*), penamaan kontrol (*naming convention*), dan kerapian properti form.

⚡ Panduan Aspek Tantangan & Kerapian Layout

Untuk membedakan hasil kerja siswa standar dengan siswa yang memiliki pemahaman rekayasa UI mendalam, terapkan 4 prinsip berikut:

1. Urutan Alur TabIndex (Fokus Kursor)

Ketika form dijalankan dan siswa menekan tombol Tab, kursor harus berpindah secara sekuensial dan teratur dari kiri ke kanan, atas ke bawah:

txtNIS (1) ➔ txtNamaSiswa (2) ➔ cmbKelas (3) ➔ dtpTanggal (4) ➔ cmbJenis (5) ➔ numBerat (6) ➔ rdoTabungan (7) ➔ rdoDonasi (8) ➔ btnTambah (9) ➔ btnSimpan (10) ...

2. Responsivitas Jendela (Anchor & Dock)

Saat jendela FrmDataSetoran di-maximize, form tidak boleh terlihat 'kopong' di sisi kanan:

  • grpEntriData: Diatur Anchor = Top, Left, Right agar melebar horizontal.
  • grpTabel & dgvSetoranSampah: Diatur Anchor = Top, Bottom, Left, Right agar otomatis mengisi seluruh ruang bawah form.

3. Standar Penamaan Komponen (Naming Convention)

Dilarang membiarkan nama default seperti button1 atau textBox3. Gunakan awalan standar industri:

  • txt... untuk TextBox
  • btn... untuk Button
  • cmb... untuk ComboBox
  • num... untuk NumericUpDown
  • dtp... untuk DateTimePicker
  • dgv... untuk DataGridView

4. Access Key (Shortcut Keyboard)

Sematkan karakter ampersand (&) pada properti Text tombol:

  • &Simpan Data $\rightarrow$ Pengguna dapat menekan Alt + S
  • &Ubah $\rightarrow$ Shortcut Alt + U
  • &Hapus $\rightarrow$ Shortcut Alt + H
