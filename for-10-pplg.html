Fondasi Perulangan (For Loop)

Konsep Mekanisme Iterasi, Anatomi 3 Komponen Kontrol, dan Lembar Praktik Terarah

Topik Bahasan Struktur Perulangan Terhitung (Definite Loop) menggunakan For
Target Kompetensi Memahami Anatomi For, Iterasi Maju, Iterasi Mundur, dan Pola Langkah Nilai
Prasyarat Variabel, Operator Perbandingan (<, <=, >, >=), dan Operator Increment/Decrement

1. Apa Itu Perulangan For?

Komputer unggul dalam mengeksekusi instruksi yang sama berulang kali dengan kecepatan tinggi tanpa melakukan kesalahan hitung. Menulis baris instruksi yang sama secara berulang-ulang secara manual sangat rentan kesalahan (*human error*) dan melanggar prinsip dasar pemrograman efisien.

For Loop adalah struktur kontrol perulangan terhitung (*definite loop*), yang berarti jumlah putarannya umumnya sudah diketahui atau bisa diprediksi sebelum loop mulai dieksekusi.

Analogi Putaran Lari di Lapangan Bayangkan guru olahraga memerintahkan siswa berlari sebanyak 5 putaran:
  • Mulai: Siswa menyiapkan catatan di putaran ke-1.
  • Cek Syarat: Selama putaran belum melebihi 5, siswa terus berlari.
  • Pembaruan: Setiap selesai melewati garis batas, hitungan putaran bertambah 1.
  • Berhenti: Begitu hitungan mencapai 6, siswa berhenti.

2. Tiga Pilar Anatomi For Loop

Perulangan for dikendalikan oleh tiga ekspresi utama yang dipisahkan oleh tanda titik koma (;):

for (inisialisasi; kondisi_berhenti; perubahan_nilai) {
    // Blok kode yang akan diulang
}
Komponen Fungsi Kerja Kapan Dijalankan?
1. Inisialisasi
int i = 0;		 Membuat variabel penghitung (*loop counter*) dan menentukan nilai awal mulainya. Hanya dijalankan satu kali tepat saat loop pertama kali dimulai.
2. Kondisi Berhenti
i < 5;		 Ekspresi logika bernilai benar/salah (*true/false*). Loop hanya berputar jika kondisi bernilai true. Diperiksa sebelum blok instruksi di dalam kurung kurawal dijalankan.
3. Perubahan Nilai
i++		 Mengubah nilai variabel counter (menambah atau mengurangi) agar mendekati kondisi berhenti. Dijalankan secara otomatis setiap akhir putaran.

Tabel Penelusuran Alur Kerja (Trace Table)

Mari kita bedah eksekusi kode: for (int i = 1; i <= 3; i++)

Putaran Nilai i Awal Cek Kondisi (i <= 3) Aksi yang Dilakukan Pembaruan (i++)
Ke-1 1 1 <= 3 → BENAR Jalankan isi loop i berubah jadi 2
Ke-2 2 2 <= 3 → BENAR Jalankan isi loop i berubah jadi 3
Ke-3 3 3 <= 3 → BENAR Jalankan isi loop i berubah jadi 4
Ke-4 4 4 <= 3 → SALAH Loop Berhenti (Keluar) -

3. Ragam Pola Perulangan For

Pola 1: Iterasi Maju (Increment)

Bergerak dari nilai kecil ke nilai besar dengan penambahan 1 nilai per putaran.

for (int i = 1; i <= 5; i++) {
    cout << i << " "; // Output: 1 2 3 4 5
}

Pola 2: Iterasi Mundur (Decrement)

Bergerak dari nilai besar ke nilai kecil menggunakan pengurangan (i--). Nilai awal harus lebih besar dari batas kondisi.

for (int i = 5; i >= 1; i--) {
    cout << i << " "; // Output: 5 4 3 2 1
}

Pola 3: Lompatan Nilai Kustom (Step Increments)

Penghitung tidak harus bertambah 1. Kita bisa mengatur lompatan angka ganjil/genap menggunakan operator penugasan majemuk (i += 2, i += 5).

for (int i = 0; i <= 10; i += 2) {
    cout << i << " "; // Output: 0 2 4 6 8 10
}

4. Kesalahan Klasik yang Wajib Dihindari

1. Perulangan Tanpa Akhir (Infinite Loop) Jika pembaruan nilai salah arah sehingga kondisi berhenti tidak pernah tercapai, loop akan berjalan selamanya dan menghabiskan sumber daya sistem komputer: 
// SALAH: i dimulai dari 10 dan terus membesar, sehingga i >= 1 selalu bernilai BENAR
for (int i = 10; i >= 1; i++) { 
    cout << i; 
}
2. Jebakan Tanda Titik Koma Palsu Meletakkan titik koma langsung setelah penutup kurung for (...) akan membuat compiler menganggap badan loop kosong. Baris di bawahnya hanya akan dieksekusi satu kali setelah loop selesai. 
// SALAH: Titik koma mengakhiri loop sebelum kurung kurawal
for (int i = 0; i < 5; i++); 
{
    cout << "Ini hanya tercetak satu kali saja!" << endl;
}

5. Latihan Terbimbing (Contoh Kasus & Solusi Kode)

Pelajari dua contoh implementasi loop berikut untuk memahami pola penulisan logika yang benar:

Latihan Terbimbing 1: Hitung Mundur Peluncuran Roket

Kasus: Buat program hitung mundur peluncuran roket dari angka 5 sampai 1, diakhiri dengan cetakan pesan peluncuran.

Instruksi:

  1. Gunakan perulangan mundur mulai dari i = 5 hingga i >= 1.
  2. Gunakan i-- untuk mengurangi hitungan per detik.
  3. Cetak status hitungan di tiap putaran, lalu cetak pesan sukses di luar blok perulangan.
Source Code (C++):
#include <iostream>
using namespace std;

int main() {
    cout << "--- Persiapan Peluncuran ---" << endl;

    for (int i = 5; i >= 1; i--) {
        cout << "Hitungan ke-" << i << " detik..." << endl;
    }

    cout << "Roket Meluncur ke Angkasa!" << endl;

    return 0;
}
Luaran Konsol (Output):
--- Persiapan Peluncuran ---
Hitungan ke-5 detik...
Hitungan ke-4 detik...
Hitungan ke-3 detik...
Hitungan ke-2 detik...
Hitungan ke-1 detik...
Roket Meluncur ke Angkasa!

Latihan Terbimbing 2: Akumulasi Penjumlahan Bilangan Bulat

Kasus: Hitung total penjumlahan bilangan bulat berurutan dari angka 1 hingga 5 (1 + 2 + 3 + 4 + 5).

Source Code (C++):
#include <iostream>
using namespace std;

int main() {
    int total = 0; // Variabel penampung akumulasi nilai

    for (int i = 1; i <= 5; i++) {
        total = total + i; // Menambahkan nilai i saat ini ke dalam total
        cout << "Menambahkan " << i << " → Total Sementara = " << total << endl;
    }

    cout << "\nHasil Akhir Penjumlahan: " << total << endl;

    return 0;
}
Luaran Konsol (Output):
Menambahkan 1 → Total Sementara = 1
Menambahkan 2 → Total Sementara = 3
Menambahkan 3 → Total Sementara = 6
Menambahkan 4 → Total Sementara = 10
Menambahkan 5 → Total Sementara = 15

Hasil Akhir Penjumlahan: 15

6. Lembar Praktik Mandiri Siswa (Tantangan)

Tulis program lengkap untuk ketiga tantangan berikut di editor kodemu. Bangun logikanya secara mandiri dan pastikan hasil cetakan di layar konsol persis seperti target output.

Tantangan 1: Cetak Tabel Kelipatan 7

Skenario Kasus: Kamu diminta membuat tabel perkalian dasar untuk membantu murid sekolah dasar menghafal perkalian 7 dari pengali 1 sampai 6.

Tugas Kamu:

  1. Gunakan perulangan for dengan variabel pengali i bergerak dari 1 hingga 6.
  2. Di dalam loop, hitung hasil perkalian 7 * i.
  3. Cetak format perkalian baris demi baris ke layar konsol.
Target Luaran Konsol:
--- Tabel Perkalian 7 ---
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42

Tantangan 2: Pengisian Baterai Perangkat (Lompatan Nilai)

Skenario Kasus: Simulasikan indikator persentase pengisian daya cepat (*fast charging*) dari baterai kosong (0%) hingga penuh (100%), di mana setiap tahap daya bertambah sebesar 20%.

Tugas Kamu:

  1. Gunakan variabel persentase persen dimulai dari 0 dengan batas berhenti <= 100.
  2. Gunakan perubahan nilai lompatan kustom sebesar 20 (persen += 20).
  3. Cetak status pengisian daya pada setiap kenaikan persentase.
  4. Setelah perulangan selesai, cetak teks bahwa baterai telah terisi penuh.
Target Luaran Konsol:
Mengisi Daya: 0%
Mengisi Daya: 20%
Mengisi Daya: 40%
Mengisi Daya: 60%
Mengisi Daya: 80%
Mengisi Daya: 100%
Status: Pengisian Daya Selesai!

Tantangan 3: Penjumlahan Bilangan Genap

Skenario Kasus: Buat program untuk menghitung total akumulasi seluruh bilangan genap positif yang berada di antara angka 2 hingga 10 (yaitu: 2 + 4 + 6 + 8 + 10).

Tugas Kamu:

  1. Siapkan variabel penampung totalGenap = 0 sebelum loop.
  2. Gunakan perulangan for yang bergerak dari angka 2 hingga 10 dengan pertambahan 2 setiap putaran.
  3. Tambahkan nilai perulangan saat ini ke variabel totalGenap.
  4. Tampilkan nilai akhir dari hasil penjumlahan tersebut.
Target Luaran Konsol:
Menghitung deret: 2 + 4 + 6 + 8 + 10
Hasil Akhir Penjumlahan Bilangan Genap: 30

7. Rangkuman Materi

  • Definisi: Perulangan for ideal digunakan ketika jumlah putaran eksekusi sudah dapat dipastikan sejak awal (*definite iteration*).
  • Struktur 3 Elemen: for (inisialisasi; kondisi; pembaruan).
  • Arah Alur: Bisa berjalan maju (i++ atau i += n) maupun mundur (i-- atau i -= n).
  • Pencegahan Error: Pastikan pembaruan nilai variabel counter selalu bergerak mendekati kondisi false agar tidak terjebak dalam *infinite loop*.
