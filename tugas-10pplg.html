Variabel, Tipe Data & Evaluasi Ekspresi C++

💡 Petunjuk Pengerjaan Review: Bagian review ini dikerjakan langsung di halaman web ini. Pilih jawaban Anda lalu klik tombol "Periksa Jawaban" untuk melihat hasil dan koreksinya seketika. TIDAK PERLU ditulis di kertas folio! (Kertas folio hanya untuk Latihan Mandiri & Evaluasi).

1. Konsep Dasar Variabel di Memori

Variabel adalah wadah atau kotak penyimpanan bernama di memori RAM komputer. Di dalam C++, setiap variabel memiliki aturan mutlak:

  • Deklarasi Wajib Menyebut Tipe: Komputer harus tahu apa jenis isi kotak tersebut sejak awal.
  • Inisialisasi: Memberi nilai awal saat variabel pertama kali dibuat (contoh: int usia = 15;). Jika variabel lokal tidak diinisialisasi, isinya berupa nilai acak (*garbage value*).

2. Tipe Data Primitif C++

Tipe Data Ukuran Memori Contoh Nilai Karakteristik Kunci
int 4 byte (32-bit) -10, 0, 250 Bilangan bulat tanpa desimal.
double / float 8 byte / 4 byte 3.14, -0.5, 85.75 Bilangan berkoma / desimal pecahan.
char 1 byte 'A', '9', '#' Karakter tunggal dengan tanda petik tunggal (').
string Dinamis "SMK Negeri 1" Kumpulan teks dengan tanda petik ganda (").
bool 1 byte true (1) atau false (0) Logika benar atau salah.

3. Jebakan Klasik: Integer Division (Pembagian Bulat)

PENTING: Di C++, jika bilangan bulat (int) dibagi dengan bilangan bulat (int), hasilnya akan dipotong bulat (angka di belakang koma dibuang).
Contoh: 5 / 2 bernilai 2 (bukan 2.5).
Agar mendapatkan pecahan 2.5, minimal salah satu angka harus pecahan desimal: 5.0 / 2 atau 5 / 2.0.

Logika Percabangan (Conditional Statements) C++

💡 Petunjuk Pengerjaan Review: Bagian review ini dikerjakan langsung di halaman web ini. Pilih jawaban Anda lalu klik tombol "Periksa Jawaban" untuk melihat koreksi instan.

1. Struktur Percabangan di C++

  • if Tunggal: Blok instruksi hanya dijalankan jika kondisi bernilai true.
  • if - else: Dua cabang alternatif (benar jalankan if, salah jalankan else).
  • if - else if - else: Memeriksa kondisi berjenjang. Begitu satu kondisi cocok, blok dijalankan dan seluruh cabang di bawahnya dilewati (*skip*).

2. Jebakan Fatal: Penugasan (`=`) vs Pembanding (`==`)

BAHAYA LOGIKA:
• Operator == (sama dengan ganda) digunakan untuk **menguji kesetaraan**.
• Operator = (sama dengan tunggal) digunakan untuk **mengisi nilai variabel**.
Di C++, jika Anda menulis if (x = 5), angka 5 dimasukkan ke x, dan angka 5 bernilai true (semua angka bukan nol dianggap benar). Akibatnya blok if akan **selalu berjalan tanpa peduli nilai sebelumnya**!

Perulangan Terkontrol (While Loop) C++

💡 Petunjuk Pengerjaan Review: Bagian review ini dikerjakan langsung di halaman web ini. Pilih jawaban Anda lalu klik tombol "Periksa Jawaban" untuk melihat koreksi instan.

1. Tiga Syarat Mutlak While Loop

  1. Inisialisasi Counter: Nilai awal variabel pencatat iterasi sebelum loop (contoh: int i = 1;).
  2. Kondisi Pengujian: Syarat agar perulangan terus berputar (contoh: i <= 5;).
  3. Update / Increment Counter: Perubahan nilai pencatat di setiap putaran (contoh: i++;). Jika lupa ditulis, program mengalami Infinite Loop (macet/hang).

2. Kuis Latihan Cepat & Koreksi Langsung

Subprogram di C++: Prosedur & Fungsi

Kini setelah seluruh fondasi dasar mantap, kita masuk ke inti materi: membagi program besar menjadi bagian-bagian terpisah yang rapi.

1. Mengapa Perlu Prosedur & Fungsi?

Dalam C++, kita bisa menulis subprogram di luar dan di atas int main(). Manfaat utamanya adalah prinsip DRY (Don't Repeat Yourself): sekali dibuat, subprogram dapat dipanggil berkali-kali tanpa menulis ulang rumusnya.

2. Prosedur (`void`) vs Fungsi (`return`)

Jenis Prosedur (Procedure) Fungsi (Function)
Tipe Return Diawali kata kunci void. Diawali tipe data kembalian (int, double, bool, dll).
Fokus Tugas Melakukan tindakan/aksi cetak ke layar. Menghitung atau mengolah data untuk menghasilkan nilai baru.
Kewajiban return Tidak memerlukan nilai return. Wajib mengembalikan hasil lewat return nilai_hasil;.
Pemanggilan Dipanggil langsung namanya:
cetakGaris();		 Hasilnya ditampung ke variabel atau diolah:
int luas = hitungLuas(10, 5);

3. Contoh Kode C++

#include <iostream>
using namespace std;

// 1. PROSEDUR (void): Bertugas menampilkan garis pemisah
void cetakGaris() {
    cout << "------------------------------" << endl;
}

// 2. FUNGSI (int): Bertugas mengalikan dan mengembalikan angka
int hitungLuasPersegi(int sisi) {
    return sisi * sisi; // Mengembalikan nilai luas
}

int main() {
    cetakGaris(); // Memanggil prosedur
    
    int luas = hitungLuasPersegi(6); // Memanggil fungsi
    cout << "Luas Persegi: " << luas << " cm2" << endl;
    
    cetakGaris();
    return 0;
}
Batas Hidup Variabel di Memori Tahap 5 • Scope & Shadowing

Cakupan Variabel: Scope & Variable Shadowing di C++

1. Variabel Lokal vs Variabel Global

  • Variabel Lokal: Dideklarasikan di dalam kurung kurawal { } suatu fungsi. Hanya hidup di blok tersebut dan langsung dihancurkan saat keluar dari }.
  • Variabel Global: Dideklarasikan di luar seluruh fungsi (paling atas). Variabel ini dapat diakses bersama oleh seluruh fungsi.

2. Variable Shadowing (Benturan Nama Variabel)

Aturan Prioritas C++: Jika nama variabel lokal atau parameter fungsi **sama persis** dengan nama variabel global di luar, fungsi akan selalu memprioritaskan variabel lokal miliknya sendiri. Variabel global akan "tertutupi" (*shadowed*). 
#include <iostream>
using namespace std;

int angka = 100; // Variabel Global

void ubahAngka(int angka) { // Parameter lokal menutupi variabel global
    angka = angka + 50;      // Yang berubah HANYA variabel parameter lokal
}

int main() {
    ubahAngka(angka);
    cout << angka << endl;  // Tetap mencetak 100 (Variabel global tidak berubah)
    return 0;
}

Ringkasan Teori Cepat C++

Variabel, Kondisi & While

Integer Division: 5 / 2 bernilai 2. Gunakan desimal 5.0 / 2 agar bernilai 2.5.

Assignment vs Equality: == membandingkan kesetaraan, sedangkan = mengisi/menugaskan nilai.

While Loop: Butuh inisialisasi counter, kondisi pengujian, dan increment (i++) agar tidak terjadi infinite loop.

Prosedur vs Fungsi C++

Prosedur: Tipe return void. Melakukan tindakan/aksi cetak teks. Tidak mengembalikan nilai.

Fungsi: Memiliki tipe return (int, double, dll). Memproses input dan wajib mengembalikan nilai lewat perintah return nilai;.

Scope & Variable Shadowing

Variabel Lokal: Hidup di dalam kurung kurawal { } dan dihancurkan saat keluar blok.

Variabel Global: Dideklarasikan di luar seluruh fungsi, dikenali oleh semua fungsi.

Shadowing: Parameter/variabel lokal yang bernama sama akan menutupi variabel global.
