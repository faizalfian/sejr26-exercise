Soal 1: Perancangan Tabel IPO & Percabangan C#

Alokasi waktu: 2 JP (90 menit) • Topik: studi kasus ekspedisi logistik

Deskripsi Studi Kasus:

Sebuah aplikasi pengiriman barang berbasis C# menghitung total ongkos kirim paket dengan aturan bisnis berikut:

  • Tarif berat: Rp10.000 untuk 1 kg pertama. Setiap kilogram tambahan dikenakan Rp6.000. Bulatkan berat ke atas ke kilogram utuh dengan Math.Ceiling(...) sebelum menghitung tarif.
  • Pengali wilayah: Zona 1 (jarak ≤ 20 km: pengali 1,0), Zona 2 (20 km < jarak ≤ 100 km: pengali 1,3), Zona 3 (jarak > 100 km: pengali 1,8). Dalam kode C#, tulis bilangan desimal dengan titik.
  • Biaya volume: Jika volume paket (panjang × lebar × tinggi dalam cm) > 10.000 cm³, tambahkan biaya tetap Rp15.000.
  • Asuransi (opsional): Jika dipilih, biayanya 0,5% dari harga barang, minimal Rp5.000. Jika tidak dipilih, biayanya Rp0.
  • Diskon anggota: Gold 15%, Silver 5%, Reguler 0% dari subtotal setelah pengali wilayah dan biaya volume, sebelum asuransi.

Urutan perhitungan: Hitung tarif berat, kalikan dengan pengali wilayah, tambahkan biaya volume, kurangi diskon anggota, lalu tambahkan asuransi. Bulatkan total akhir ke atas ke rupiah utuh. Asumsikan jarak, dimensi, dan harga barang bernilai valid; berat harus lebih dari 0.

Contoh Format Tabel IPO (Input - Process - Output):

Sebagai referensi cara menyusun, berikut contoh tabel IPO untuk aplikasi kasir sederhana:

Soal 2: Tabel Penelusuran Array C#

Alokasi waktu: 2 JP (90 menit) • Topik: perubahan isi array dan perulangan bersarang

Perhatikan potongan program C# berikut. Program ini mengolah elemen array dan mengubah nilai array secara dinamis selama perulangan berjalan:

int[] A = new int[] { 4, 7, 2, 9, 5 };
int total = 0;
int langkah = 0;

for (int i = 0; i < 4; i++)
{
    for (int j = i + 1; j < 5; j++)
    {
        langkah++;
        if ((A[i] + A[j]) % 3 == 0)
        {
            total += (A[i] * 2) - A[j];
            A[j] = A[j] + 1;
        }
        else
        {
            total += (A[j] - A[i]);
            A[i] = A[i] + (langkah % 2);
        }
    }
}
Console.WriteLine($"Total Akhir = {total}");

Instruksi Tugas Kertas:

Buat tabel penelusuran (trace table) dengan enam kolom seperti contoh di kertas folio Anda. Isi satu baris untuk setiap putaran perulangan terdalam, seluruhnya 10 iterasi. Gunakan nilai array terbaru pada setiap iterasi.

Iterasi Nilai i Nilai j Kondisi ((A[i]+A[j]) % 3 == 0) Perubahan 'total' Kondisi Array A
1 0 1 (4 + 7) % 3 == 2 → FALSE total = 0 + (7 - 4) = 3 {5, 7, 2, 9, 5}
2 0 2 ... ... ...
Lanjutkan secara manual sampai iterasi ke-10 di kertas folio Anda...

1. Kode sumber program

Berikut adalah program C# untuk menghitung rata-rata nilai siswa dan kelulusan. Perhatikan nomor baris di sebelah kiri:

1using System;

3class Program

5    static double HitungRataRata(int[] nilai, int jumlah)

2. Empat kesalahan yang perlu dicari

Pelajari keempat kesalahan di bawah ini. Bedakan kesalahan yang berpotensi terjadi pada suatu baris dari perilaku yang benar-benar terjadi ketika program dijalankan dari awal.

  • Indeks array di luar batas: Indeks nilai yang valid adalah 0 sampai nilai.Length - 1. Periksa apa yang terjadi jika jumlah sama dengan panjang array.
  • Pembagian dengan nol: Pada pemanggilan pertama, jumlah bernilai 0. Karena sum bertipe double, hasil pembagian bilangan positif dengan nol adalah PositiveInfinity, bukan pengecualian.
  • Perulangan tanpa akhir: Tanpa { }, badan while hanya terdiri atas satu pernyataan. n++ berada di luar perulangan, sehingga n tidak berubah selama perulangan.
  • Penugasan dalam kondisi: if (isRemidi = true) mengubah nilai isRemidi menjadi true; kondisi tersebut selalu benar. Gunakan nilai variabel sebagai kondisi, misalnya if (isRemidi).

Soal 4: Pemrograman Modular: Prosedur & Fungsi di C#

Alokasi waktu: 120 menit; sisakan 15 menit untuk refleksi dan pengumpulan • Topik: prosedur, fungsi, dan studi kasus parkir

1. Konsep Dasar: Apa Itu Pemrograman Modular & Subprogram?

Selama ini kita terbiasa menulis semua baris program menumpuk di dalam satu blok besar, yaitu Main(). Bayangkan jika sebuah aplikasi kasir atau game memiliki 1.000 baris kode yang ditulis bercampur aduk di satu tempat. Kode akan menjadi sangat rumit, sulit dicari kesalahannya, dan jika kita butuh rumus yang sama di 5 tempat berbeda, kita terpaksa salin-tempel kode berkali-kali.

Pemrograman Modular adalah teknik memecah program besar yang rumit menjadi bagian-bagian kecil yang mandiri. Bagian kecil ini disebut Subprogram (atau istilah umumnya dalam C# adalah Method).

2. Perbedaan Mendasar: Prosedur vs Fungsi

Dalam ilmu algoritma dan pemrograman, subprogram dibagi menjadi dua jenis utama:

Pembeda Prosedur (Procedure) Fungsi (Function)
Tujuan Melakukan serangkaian aksi / tugas tertentu (misal: mencetak struk, menampilkan menu, membersihkan layar). Melakukan perhitungan atau pemrosesan data untuk menghasilkan suatu nilai baru.
Nilai Kembalian TIDAK mengembalikan nilai ke pemanggilnya. MENGEMBALIKAN nilai (return value) ke pemanggilnya.
Tanda di C# Menggunakan kata kunci void sebagai tipe return. Menggunakan tipe data tertentu (seperti int, double, string, bool).
Kata Kunci return Tidak memerlukan return nilai;. Harus mengembalikan nilai pada setiap jalur eksekusi yang dapat dicapai; return tidak harus berada di baris terakhir.
Cara Memanggil Cukup dipanggil namanya:
CetakGaris();		 Hasilnya biasanya ditampung ke dalam variabel:
int total = HitungLuas(10, 5);

3. Mengapa Ada Kata Kunci static di C#?

Saat melihat kode C#, siswa sering bingung: "Kenapa selalu ada kata static di depan prosedur atau fungsi kita?"

Penjelasan Sederhana:
Dalam C#, metode utama program kita adalah static void Main().
Aturan dasar C# menyatakan bahwa sebuah subprogram yang bertipe static (seperti Main) hanya bisa memanggil langsung subprogram lain yang juga diberi label static.
Jika kita tidak menambahkan kata static, C# akan mewajibkan kita membuat "objek baru" terlebih dahulu menggunakan perintah new (materi Object-Oriented Programming). Agar kita bisa langsung memanggil prosedur atau fungsi buatan kita dengan mudah di dalam Main(), kita cukup menambahkan kata kunci static di depannya.

4. Contoh Kode Pembanding: Prosedur vs Fungsi

Perhatikan contoh program C# di bawah ini. Cermati bagaimana Prosedur dan Fungsi ditulis serta bagaimana cara memanggilnya:

using System;

class Program
{
    // -------------------------------------------------------------
    // CONTOH 1: PROSEDUR (Menggunakan 'void', tidak mengembalikan nilai)
    // Tugasnya hanya melakukan aksi: mencetak header karcis ke layar
    // -------------------------------------------------------------
    static void CetakHeaderKarcis(string namaMall)
    {
        Console.WriteLine("==============================");
        Console.WriteLine($"   PARKIR OTOMATIS {namaMall.ToUpper()}   ");
        Console.WriteLine("==============================");
    }

    // -------------------------------------------------------------
    // CONTOH 2: FUNGSI (Mengembalikan tipe 'int', wajib ada 'return')
    // Tugasnya memproses angka: mengonversi selisih menit menjadi jam bulat
    // -------------------------------------------------------------
    static int HitungDurasiJam(int menitMasuk, int menitKeluar)
    {
        int selisihMenit = menitKeluar - menitMasuk;
        if (selisihMenit <= 0)
        {
            return 1; // Minimal dihitung 1 jam
        }
        
        // Rumus pembulatan ke atas (misal 65 menit jadi 2 jam)
        int jamBulat = (int)Math.Ceiling(selisihMenit / 60.0);
        return jamBulat; // Nilai jam dikirim kembali ke pemanggil
    }

    static void Main()
    {
        // Cara 1: Memanggil Prosedur (langsung sebut nama & argumennya)
        CetakHeaderKarcis("Grand City Mall");

        // Cara 2: Memanggil Fungsi (tampung hasil return-nya ke variabel)
        int jamParkir = HitungDurasiJam(480, 620); // Masuk 08:00 (480m), Keluar 10:20 (620m)
        
        Console.WriteLine($"Lama Parkir: {jamParkir} Jam");
    }
}

5. Studi Kasus Latihan: Sistem Tarif Parkir Otomatis

Sekarang giliran Anda merancang subprogram modular untuk sistem parkir. Aturan tarif parkir adalah:

  • Motor: Rp2.000 untuk 1–2 jam pertama. Setiap jam berikutnya Rp1.000 per jam. Tarif dasar maksimal Rp15.000.
  • Mobil: Rp5.000 untuk 1 jam pertama. Setiap jam berikutnya Rp3.000 per jam. Tarif dasar maksimal Rp35.000.
  • Denda tiket hilang: Tambahkan biaya tetap Rp25.000 jika tiket berstatus hilang. Denda tidak termasuk dalam batas maksimal tarif dasar.

Asumsi latihan: Jenis kendaraan hanya Motor atau Mobil; durasi parkir 1–24 jam dalam hari yang sama. Waktu masuk dan keluar dinyatakan sebagai jumlah menit sejak pukul 00.00, dengan waktu keluar lebih besar daripada waktu masuk.
