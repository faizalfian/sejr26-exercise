📖 Skenario 1: Gerbang Parkir Sekolah (Soal 1–4)

Gerbang parkir sekolah hanya menyediakan tiga tempat kosong. Kendaraan bernomor ganjil adalah motor dengan biaya Rp2.000, sedangkan kendaraan bernomor genap adalah mobil dengan biaya Rp5.000.

int tempat = 3;
int pendapatan = 0;
int kendaraan = 1;

while (kendaraan <= 5) {
    if (tempat > 0) {
        if (kendaraan % 2 == 1) {
            pendapatan += 2000;
            cout << "Motor masuk" << endl;
        } else {
            pendapatan += 5000;
            cout << "Mobil masuk" << endl;
        }
        tempat--;
    } else {
        cout << "Parkir penuh" << endl;
    }
    kendaraan++;
}
cout << "Pendapatan: " << pendapatan << endl;

  • C. tempat = 1, pendapatan = 9000
  • D. tempat = 2, pendapatan = 5000

📖 Skenario 2: Mesin Minuman Otomatis (Soal 5–8)

Sebuah mesin minuman melayani empat pembeli. Pembeli bernomor kelipatan tiga memilih jus seharga Rp7.000, pembeli lainnya memilih air mineral seharga Rp3.000. Mesin hanya memiliki tiga botol stok.

int stok = 3;
int uang = 0;
int pembeli = 1;

while (pembeli <= 4) {
    int harga;
    if (pembeli % 3 == 0) {
        harga = 7000;
    } else {
        harga = 3000;
    }

    if (stok > 0) {
        stok--;
        uang += harga;
        cout << "Minuman keluar" << endl;
    } else {
        cout << "Stok habis" << endl;
    }
    pembeli++;
}
cout << "Uang: " << uang << endl;

📖 Skenario 3: Pengembalian Buku Perpustakaan (Soal 9–12)

Perpustakaan menghitung denda empat anggota. Setiap anggota terlambat sejumlah hari yang meningkat dua hari. Telat lebih dari lima hari dikenai denda Rp4.000 per hari; selain itu Rp2.000 per hari.

int anggota = 1;
int telat = 2;
int total_denda = 0;
int terlambat_berat = 0;

while (anggota <= 4) {
    int denda;
    if (telat > 5) {
        denda = telat * 4000;
        terlambat_berat++;
    } else {
        denda = telat * 2000;
    }
    total_denda += denda;
    telat += 2;
    anggota++;
}
cout << "Total denda: " << total_denda << endl;
cout << "Telat berat: " << terlambat_berat << endl;

📖 Skenario 4: Sensor Kebun Hidroponik (Soal 13–16)

Sensor membaca kelembapan air pada kebun hidroponik. Jika kelembapan di bawah 40, pompa menyala dan menambah kelembapan 25. Jika tidak, kelembapan berkurang 10 setelah tanaman menyerap air.

int kelembapan = 35;
int putaran = 1;
int pompa_menyala = 0;

while (putaran <= 4) {
    if (kelembapan < 40) {
        pompa_menyala++;
        kelembapan += 25;
        cout << "Pompa ON" << endl;
    } else {
        kelembapan -= 10;
        cout << "Pompa OFF" << endl;
    }
    putaran++;
}
cout << "Kelembapan akhir: " << kelembapan << endl;
cout << "Pompa menyala: " << pompa_menyala << endl;

📖 Skenario 5: Robot Pembersih Kelas (Soal 17–20)

Robot pembersih memiliki baterai 70. Ia membersihkan maksimal lima zona. Setiap zona memerlukan 15 baterai. Zona bernomor genap memiliki sampah berat sehingga menambah 10 poin sampah terkumpul; zona ganjil menambah 5 poin.

int baterai = 70;
int zona = 1;
int sampah = 0;

while (zona <= 5 && baterai >= 15) {
    baterai -= 15;

    if (zona % 2 == 0) {
        sampah += 10;
        cout << "Sampah berat" << endl;
    } else {
        sampah += 5;
        cout << "Sampah ringan" << endl;
    }
    zona++;
}
cout << "Zona selesai: " << zona - 1 << endl;
cout << "Sampah: " << sampah << endl;
cout << "Baterai: " << baterai << endl;
