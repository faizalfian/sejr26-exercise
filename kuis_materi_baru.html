Latihan Soal Materi Baru C++

Kerjakan soal-soal di bawah ini. Setelah selesai, klik tombol Koreksi Jawaban di bagian paling bawah.

1. Perhatikan potongan kode pembacaan input bertumpuk (chained cin) berikut:
int panjang, lebar; cin >> panjang >> lebar; cout << panjang * lebar;
Jika pengguna menjalankan program dan mengetikkan `5 10` (dipisah spasi) lalu menekan Enter, apa yang akan terjadi?
2. Di C++, bagaimana cara yang paling tepat untuk mendeklarasikan nilai PI yang bernilai 3.14 agar nilainya dikunci dan tidak bisa diubah secara tidak sengaja oleh programer di baris kode selanjutnya?
3. Perhatikan jebakan pembagian tipe data primitif berikut:
int hasil = 7 / 2; cout << hasil;
Berapakah output yang akan ditampilkan di layar terminal?
4. Agar ekspresi pembagian dua variabel bilangan bulat `int a = 7` dan `int b = 2` dapat menghasilkan bilangan pecahan yang presisi (yaitu 3.5), operasi mana yang benar menggunakan metode type casting di C++?
5. Dalam struktur percabangan `switch-case`, kata kunci apa yang wajib digunakan pada setiap akhir blok nilai untuk menghentikan pengecekan dan keluar dari `switch` agar blok di bawahnya tidak ikut tereksekusi?
6. Blok penampung pada struktur `switch-case` yang berfungsi menyerupai klausa `else` (yakni dieksekusi secara otomatis jika tidak ada satupun kondisi nilai `case` yang cocok) dideklarasikan dengan kata kunci...
7. Perhatikan transformasi sintaks perulangan menjadi tipe `for` berikut:
for (int i = 1; i <= 5; i++) { cout << i << " "; }
Manakah bagian dari deklarasi kurung `for` tersebut yang bertindak mengatur update nilai / increment?
8. Apa sifat khas yang paling membedakan perulangan `do-while` dibandingkan dengan perulangan `while`?
