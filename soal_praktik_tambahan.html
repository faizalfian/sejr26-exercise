Kasir Kantin Sekolah

Praktik Pemrograman C++ · Fase E / Kelas X PPLG · Semester Gasal
Medium — 35 Poin

Konsep yang diuji: perulangan while, percabangan if – else if – else, akumulator, diskon, dan penghentian perulangan dengan kode 0.

Ketentuan pengerjaan
  • Gunakan if, else if, dan/atau else untuk seleksi; dilarang menggunakan switch-case.
  • Gunakan while untuk perulangan; dilarang menggunakan for dan do-while.
  • Tulis program C++ dengan format keluaran persis seperti spesifikasi, tanpa pesan permintaan input tambahan.

Deskripsi Masalah

Kantin sekolah membutuhkan program kasir untuk menghitung belanja seorang siswa. Program membaca nama siswa, kemudian mencatat pembelian berulang sampai kode 0 dimasukkan.

KodeMenuHarga satuan
1Nasi gorengRp 12000
2Roti isiRp 8000
3Es tehRp 4000
0Selesai belanja—

Setiap pembelian berisi kode menu dan jumlah unit. Menu yang sama boleh dibeli berkali-kali. Jumlahkan seluruh unit yang dibeli dan seluruh biaya pembelian.

Ketentuan diskon: jika subtotal belanja ≥ Rp 50000, siswa mendapat diskon 10% dari subtotal. Jika subtotal di bawah Rp 50000, diskon bernilai Rp 0. Total bayar adalah subtotal dikurangi diskon.

Jika siswa langsung memasukkan kode 0, jumlah item, subtotal, diskon, dan total bayar semuanya bernilai 0.

Spesifikasi I/O

Input (stdin)

  • Baris pertama: nama_siswa (string satu kata).
  • Baris pembelian: kode_menu jumlah, dengan kode 1, 2, atau 3 dan jumlah berupa bilangan bulat 1–100.
  • Baris terakhir: 0 saja, tanpa jumlah. Maksimal 100 baris pembelian sebelum kode 0.
  • Semua input dijamin valid dan selalu diakhiri kode 0.

Output (stdout)

Cetak satu ringkasan setelah belanja selesai. jumlah_item adalah total unit yang dibeli, bukan banyaknya baris pembelian. Semua nilai uang ditulis sebagai bilangan bulat tanpa pemisah ribuan.

Nama: <nama>
Jumlah Item: <jumlah_item>
Subtotal: Rp <subtotal>
Diskon: Rp <diskon>
Total Bayar: Rp <total_bayar>
