SOAL 1: Kasir Laundry Kiloan "Bersih Kilat"

Konsep: Percabangan Seleksi `if - else if - else`

Dasar • 25 Poin

Deskripsi Masalah

Sebuah tempat laundry kiloan melayani 3 pilihan paket layanan dengan tarif per kilogram (kg):

Kode Nama Layanan Tarif / kg
'C' / 'c' Cuci Kering Rp 5.000
'S' / 's' Setrika Saja Rp 4.000
'K' / 'k' Komplit (Cuci + Setrika) Rp 8.000

Ketentuan Promo Diskon:

  • Jika berat pakaian yang dicuci ≥ 5 kg, pelanggan mendapatkan diskon langsung sebesar Rp 3.000.
  • Jika berat pakaian < 5 kg, diskon adalah Rp 0.

Format Input & Output

Input (stdin):

  • Baris 1: nama_pelanggan (string satu kata)
  • Baris 2: kode_layanan (char: 'C', 'S', atau 'K')
  • Baris 3: berat (bilangan bulat ≥ 1)

Format Output (stdout):

Nama: <nama>
Layanan: <layanan_kapital>
Berat: <berat> kg
Total Awal: Rp <total_awal>
Diskon: Rp <diskon>
Total Bayar: Rp <total_bayar>

Uji Kasus (Test Cases)

Test Case 1 (Dapat Diskon):
Input: Rudi, K, 6
Expected Total: Rp 45000 (Diskon Rp 3000)
Test Case 2 (Tanpa Diskon):
Input: Dewi, C, 3
Expected Total: Rp 15000 (Diskon Rp 0)
Test Case 3 (Pas 5 kg):
Input: Bayu, S, 5
Expected Total: Rp 17000 (Diskon Rp 3000)

SOAL 2: Kasir Penghitung Belanja Otomatis

Konsep: Perulangan `while` & Akumulator Nilai

Dasar • 35 Poin

Deskripsi Masalah

Kasir minimarket memasukkan harga belanjaan barang satu per satu ke dalam sistem komputer sekolah menggunakan perulangan while:

  • Program terus membaca harga barang (bilangan bulat > 0) secara berulang.
  • Setiap kali harga dimasukkan, program menjumlahkannya ke total belanja dan menambah penghitung banyak_barang sebanyak 1.
  • Perulangan akan berhenti otomatis saat kasir memasukkan angka 0 (*sentinel value*).

Ketentuan Bonus Kupon:

  • Jika Total Belanja ≥ 50.000, cetak:
    Bonus: Mendapat kupon belanja!
  • Jika Total Belanja < 50.000, cetak:
    Bonus: Tidak dapat kupon.

Format Input & Output

Input (stdin):

Sejumlah baris bilangan bulat harga barang, diakhiri dengan angka 0.

Format Output (stdout):

Banyak Barang: <jumlah_barang>
Total Belanja: Rp <total>
Bonus: <keterangan_kupon>

Uji Kasus (Test Cases)

Test Case 1 (Total ≥ 50.000):
Input: 15000, 25000, 15000, 0
Output: Banyak: 3 | Total: Rp 55000 | Mendapat kupon belanja!
Test Case 2 (Total < 50.000):
Input: 10000, 12000, 0
Output: Banyak: 2 | Total: Rp 22000 | Tidak dapat kupon.
Test Case 3 (Pas Rp 50.000):
Input: 50000, 0
Output: Banyak: 1 | Total: Rp 50000 | Mendapat kupon belanja!
