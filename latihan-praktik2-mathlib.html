Fungsi Matematika (cmath), Manipulasi Double, dan Boolean

📚 Catatan Materi: Operasi Matematika Kompleks

Sebelum mengerjakan soal-soal di bawah, pelajari fungsi khusus matematika dalam C++ ini:

  • Library Tambahan: Untuk menggunakan rumus matematika, kamu wajib menambahkan #include <cmath> di baris paling atas (di bawah iostream).
  • Tipe Data Double: Jika perhitungan melibatkan angka desimal panjang atau akar kuadrat, gunakan tipe data double (jangan gunakan int karena int akan menghapus angka di belakang koma).
  • Fungsi Pangkat (Power): Gunakan pow(angka, pangkat).
    Contoh: pow(5, 2) artinya 5 pangkat 2 (hasil: 25).
  • Fungsi Akar (Square Root): Gunakan sqrt(angka).
    Contoh: sqrt(144) artinya akar dari 144 (hasil: 12).
