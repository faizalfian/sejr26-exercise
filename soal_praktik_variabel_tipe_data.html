Soal: Program Pembuatan Kartu Identitas Pelajar (KTS Digital)

Studi Kasus:
Sekolah Anda sedang memperbarui sistem informasi kesiswaan. Sebagai calon programmer kelas 10, Anda diminta membuat program C++ sederhana untuk mencetak Kartu Identitas Siswa Digital secara otomatis ke layar konsol menggunakan cout.

Instruksi & Ketentuan Soal

  1. Gunakan header file standar #include <iostream> dan #include <string>.
  2. Deklarasikan dan inisialisasi minimal 6 variabel dengan tipe data yang tepat sesuai tabel di bawah.
  3. Buat rumus perhitungan sederhana untuk variabel umur yaitu: tahunSekarang - tahunLahir.
  4. Cetak seluruh data siswa menggunakan objek cout dan manipulator baris endl (atau \n).
  5. Buat format output rapi dengan garis pemisah (border) seperti pada contoh tampilan yang diberikan.

Daftar Variabel & Tipe Data Wajib

Nama Variabel Tipe Data Contoh Nilai Awal
namaSiswa string "Ahmad Pratama"
nisn string "0089765432"
kodeKelas char 'A'
tahunLahir int 2009
tahunSekarang int 2026
nilaiUjianMasuk double / float 89.50
statusAktif bool true
