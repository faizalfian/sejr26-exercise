Contoh Terbimbing: Misi Daur Ulang GreenTech

Cerita

Klub GreenTech SMK Nusantara mengumpulkan sampah elektronik untuk diserahkan ke pusat daur ulang setelah jumlahnya mencapai minimal 100 kilogram. Pada hari pertama terkumpul 12 kilogram. Setelah kampanye dipublikasikan, jumlah yang dikumpulkan setiap hari bertambah 3 kilogram. Pusat daur ulang memberikan penghargaan Rp2.500 per kilogram.

Buat program C++ menggunakan while untuk mencari jumlah hari yang diperlukan, total sampah ketika target tercapai atau terlewati, dan nilai penghargaan.

1. Apa yang diminta?

Jumlah hari belum diketahui ketika program dimulai. Karena itu, jumlah hari tidak dapat langsung dijadikan batas tetap. Kita perlu mencari keadaan yang menentukan apakah pengumpulan masih harus dilanjutkan.

2. Informasi yang sudah diketahui

InformasiNilai
Target100 kg
Pengumpulan hari pertama12 kg
Penambahan harian3 kg
Penghargaan per kilogramRp2.500

3. Menentukan pengendali perulangan

Kegiatan berlanjut selama total sampah masih kurang dari target. Kondisi yang mewakili masalah adalah totalSampah < target. Pengendalinya adalah keadaan total sampah, bukan jumlah hari.

4. Variabel dan tipe data

5. Keadaan awal dan satu iterasi

hari = 0
totalSampah = 0
sampahHarian = 12

Dalam satu iterasi:
1. hari bertambah 1
2. totalSampah ditambah sampahHarian
3. sampahHarian bertambah 3 untuk hari berikutnya

Perulangan pasti berhenti karena totalSampah terus bertambah dan akhirnya mencapai atau melewati target.

6. Penelusuran Perulangan

HariSampah hari iniTotalPersiapan berikutnya
112 kg12 kg15 kg

318 kg45 kg21 kg

Setelah iterasi keenam, pemeriksaan berikutnya menghasilkan 117 < 100, yaitu salah. Dari proses inilah diketahui bahwa target tercapai pada hari keenam.

7. Pseudocode

SET target = 100
SET penambahanHarian = 3
SET hargaPerKg = 2500
SET hari = 0
SET sampahHarian = 12
SET totalSampah = 0

WHILE totalSampah kurang dari target
    TAMBAH hari dengan 1
    TAMBAH totalSampah dengan sampahHarian
    TAMBAH sampahHarian dengan penambahanHarian
END WHILE

SET totalPenghargaan = totalSampah dikali hargaPerKg
TAMPILKAN hari, totalSampah, dan totalPenghargaan

8. Jawaban C++

#include <iostream>
using namespace std;

int main() {
    const int target = 100;
    const int penambahanHarian = 3;
    const long long hargaPerKg = 2500;
    int hari = 0;
    int sampahHarian = 12;
    int totalSampah = 0;

    while (totalSampah < target) {
        hari++;
        totalSampah += sampahHarian;
        sampahHarian += penambahanHarian;
    }

    long long totalPenghargaan = totalSampah * hargaPerKg;
    cout << "Target tercapai dalam: " << hari << " hari" << endl;
    cout << "Total sampah: " << totalSampah << " kg" << endl;
    cout << "Total penghargaan: Rp" << totalPenghargaan << endl;
    return 0;
}

9. Output

Target tercapai dalam: 6 hari
Total sampah: 117 kg
Total penghargaan: Rp292500
