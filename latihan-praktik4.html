Modul Praktik C++: Conditionals

Logika Percabangan IF Mandiri dan Operator AND (&&)

📚 Catatan Materi: IF Mandiri & Operator Logika

1. IF yang Berdiri Sendiri (Independent IF)

Jika kita ingin mengecek beberapa kondisi secara berurutan dan semuanya bisa terjadi sekaligus, jangan gunakan else if. Gunakan if baru.

if (nilai_fisik > 80) {
    // Mengecek fisik
}
if (nilai_sihir > 70) {
    // Mengecek sihir (dijalankan walaupun fisik juga > 80)
}

2. Penggabungan Syarat Lulus (&&)

Untuk mengecek dua syarat yang keduanya harus terpenuhi, gunakan operator AND (&&).

if (skor >= 100 && stamina > 0) {
    cout << "Kamu Lulus!";
} else {
    cout << "Kamu Gagal!";
}
