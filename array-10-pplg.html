1. Apa Itu Array?

Dalam pemrograman, kita sering memerlukan penyimpanan banyak data yang sejenis. Jika kita memiliki 5 nilai ujian siswa, membuat lima variabel berbeda seperti nilai1, nilai2, hingga nilai5 sangat tidak efisien dan menyulitkan pengelolaan data.

Array adalah struktur data berurutan yang menyimpan sekumpulan nilai bertipe data sama di dalam satu wadah variabel tunggal pada lokasi memori yang bersebelahan (contiguous memory).

Analogi Loker Bernomor Bayangkan sebuah lemari loker panjang yang memiliki 5 slot laci bersebelahan. Lemari tersebut punya satu nama utama (misalnya loker), dan setiap slot diberi label nomor urut pengenal yang disebut indeks. Saat ingin menyimpan atau mengambil sesuatu, kita cukup merujuk pada nomor laci tersebut.

Aturan Emas: Indeks Dimulai dari Nol (0-Indexed)

Mayoritas bahasa pemrograman menggunakan pengindeksan berbasis nol:

  • Elemen pertama selalu berada di indeks 0.
  • Elemen kedua berada di indeks 1.
  • Jika kapasitas array adalah N, maka elemen terakhir selalu berada di indeks N - 1.
Ilustrasi Array: int nilai[5] = {80, 85, 90, 75, 95};
80 85 90 75 95
Indeks [0]
(Elemen ke-1)		 Indeks [1]
(Elemen ke-2)		 Indeks [2]
(Elemen ke-3)		 Indeks [3]
(Elemen ke-4)		 Indeks [4]
(Elemen ke-5)

2. Empat Pilar Operasi Dasar Array

Empat operasi pokok yang wajib dipahami sebelum melangkah ke algoritma lanjutan:

Pilar 1: Membuat Array (Deklarasi)

Mendeklarasikan array berarti memesan ruang di memori komputer dengan menentukan tipe data, nama variabel, dan kapasitas slotnya di dalam tanda kurung siku [ ]. 

int skor[5];        // Memesan 5 slot bilangan bulat
string murid[3];    // Memesan 3 slot teks

Pilar 2: Memasukkan Data ke Dalam Array

Pengisian data bisa dilakukan sekaligus saat dibuat atau diisi bertahap lewat nomor indeks:

// Cara A: Inisialisasi langsung saat deklarasi
int nilai[3] = {85, 90, 78};

// Cara B: Pengisian bertahap per nomor indeks
int nilai[3];
nilai[0] = 85;
nilai[1] = 90;
nilai[2] = 78;

Pilar 3: Membaca Nilai dari Dalam Array

Nilai diambil dengan menyebut nama array beserta nomor indeks slot yang dicari di dalam tanda kurung siku: 

cout << "Nilai pertama: " << nilai[0] << endl;
int total = nilai[0] + nilai[1];

Pilar 4: Mengubah Elemen di Dalam Array

Nilai di dalam slot array dapat ditimpa dengan nilai baru kapan saja tanpa merusak ukuran array: 

nilai[2] = 88; // Menimpa isi indeks ke-2 menjadi 88
cout << "Nilai setelah perbaikan: " << nilai[2] << endl;

3. Kesalahan Umum yang Sering Dilakukan Pemula

Kesalahan Batas Indeks (Out of Bounds) Array berukuran 5 elemen (int data[5]) hanya memiliki indeks yang sah dari 0 sampai 4. Mengakses data[5] berada di luar blok memori yang dialokasikan sehingga menyebabkan program berhenti mendadak (crash) atau membaca nilai yang tidak dapat diprediksi.
Membaca Nilai Sampah (Garbage Value) Pada bahasa seperti C++, mendeklarasikan array lokal tanpa mengisinya (misal int angka[3];) tidak otomatis bernilai 0. Nilai di dalamnya berisi data acak sisa penggunaan memori sebelumnya.

4. Latihan Terbimbing (Contoh Kasus & Solusi Kode)

Pelajari alur kerja program berikut sebagai model referensi implementasi 4 fondasi array:

Latihan Terbimbing 1: Papan Skor Pertandingan Game

Kasus: Catat skor atlet pada 4 ronde pertandingan, tampilkan nilai ronde awal dan akhir, lalu lakukan perbaikan pada skor ronde ke-3 karena ralat panitia.

Instruksi:

  1. Buat array integer berukuran 4 bernama skor.
  2. Isi skor masing-masing ronde: 70, 85, 60, 90.
  3. Tampilkan nilai Ronde 1 (indeks 0) dan Ronde 4 (indeks 3).
  4. Ubah nilai ronde 3 (indeks 2) yang semula 60 menjadi 75.
  5. Cetak kembali skor ronde 3 untuk memastikan perubahannya.
Source Code (C++):
#include <iostream>
using namespace std;

int main() {
    // 1. Membuat array berukuran 4 elemen
    int skor[4];

    // 2. Memasukkan data ke masing-masing slot
    skor[0] = 70;
    skor[1] = 85;
    skor[2] = 60;
    skor[3] = 90;

    // 3. Membaca data awal
    cout << "Skor Ronde 1 : " << skor[0] << endl;
    cout << "Skor Ronde 4 : " << skor[3] << endl;

    // 4. Mengubah data pada indeks ke-2
    skor[2] = 75;

    // Menampilkan hasil setelah diubah
    cout << "Skor Ronde 3 (Setelah Ralat): " << skor[2] << endl;

    return 0;
}
Luaran Konsol (Output):
Skor Ronde 1 : 70
Skor Ronde 4 : 90
Skor Ronde 3 (Setelah Ralat): 75

Latihan Terbimbing 2: Daftar Belanja Toko

Kasus: Kelola 3 nama barang belanjaan mingguan, baca elemen pertama dan terakhir, lalu ganti salah satu barang yang habis dengan barang lain.

Source Code (C++):
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1 & 2. Membuat array teks sekaligus mengisinya
    string belanja[3] = {"Beras", "Gula", "Minyak"};

    // 3. Membaca elemen pertama dan terakhir
    cout << "Barang Pertama : " << belanja[0] << endl;
    cout << "Barang Terakhir: " << belanja[2] << endl;

    // 4. Mengubah elemen indeks ke-2 karena stok minyak habis
    belanja[2] = "Kecap";

    cout << "\n--- Kondisi Terbaru ---" << endl;
    cout << "Slot [2] Terkini: " << belanja[2] << endl;

    return 0;
}
Luaran Konsol (Output):
Barang Pertama : Beras
Barang Terakhir: Minyak

--- Kondisi Terbaru ---
Slot [2] Terkini: Kecap

Tantangan 2: Inventaris Meja Instruktur Lab

Skenario Kasus: Penanggung jawab lab komputer mendata empat perangkat utama yang terpasang di meja pengajar.

Tugas Kamu:

  3. Unit Speaker di indeks 3 dipindahkan ke ruang lain dan diganti dengan "Headset". Ubah isi elemen di indeks 3.

6. Rangkuman Materi

  • Prinsip Ruang Memori: Array mengelompokkan data sejenis dalam satu deret memori yang berurutan.
  • Aturan Indeks: Berbasis nol (0 sampai N - 1, di mana $N$ adalah kapasitas array).
  • 4 Operasi Inti:
    • Membuat (Deklarasi): Menyatakan tipe data dan kapasitas ukuran tetap.
    • Memasukkan: Menempatkan data ke slot memori via inisialisasi awal atau assignment operator.
    • Membaca: Mengakses isi data dengan memanggil nomor indeksnya.
    • Mengubah: Menimpa nilai pada slot indeks tertentu tanpa menambah/mengurangi total ukuran array.
  • Keamanan Memori: Selalu batasi akses indeks maksimal pada ukuran - 1 untuk mencegah kerusakan program (out of bounds error).
